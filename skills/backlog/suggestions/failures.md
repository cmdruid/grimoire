## failures

File unexpected or intermittent test, build, or project-tool behavior only when it remains
unresolved after the current work. Expected red-green failures and failures resolved during the
current objective are not leftovers. Keep one row per failure family, identified by the component
or command, stable signature, and observed behavior; sharpen a matching open row instead of
creating a duplicate.
