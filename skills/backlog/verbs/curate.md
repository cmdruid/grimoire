# `curate` — groom living rows

Resolve roots and require the staged engine. Work only from `list [--tracker <stem>]` output.
Sharpen with `update`, finish with `complete`, remove obsolete rows with `drop`, and reprioritize
with `reorder --tracker <stem> --ids <complete-csv-permutation>`. Never edit TSV bytes.

Commit every changed tracker path once through the scoped helper. Curation does not drain work,
mint records, or change the project cookbook.
