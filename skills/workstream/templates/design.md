# Design intake brief

## Mission

Turn one uncertain change into an argued, reviewable specification that a later build session can
execute without reconstructing the important decisions.

## Unit discipline

- Ground each unit in current project constraints and affected code before proposing a design.
- Surface the load-bearing decision first; record the selected approach and rejected alternatives.
- Keep implementation sequencing separate from the specification unless the user asks for a plan.
- Review and publish the approved artifact through the host records workflow.
- Route independent implementation or follow-up work to its owning queue instead of expanding the
  design unit.
