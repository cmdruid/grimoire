# High-frequency substitutions

Derived from the Google developer documentation style guide word list (snapshot 2026-08-17). This file is the lookup. If a term isn't here: primary sense, first Merriam-Webster spelling, one term per concept.

| Don't write | Write |
|---|---|
| please / please note | drop it |
| simply / just / easily / quickly (in a procedure) | drop it |
| let's | imperative or *you* |
| allows you to / enables you to | lets you |
| desire / desired | want / need |
| currently / now / new / latest / soon / as of this writing | drop, or give a date or version |
| above / below (doc or UI position) | preceding / following, or name the control |
| click here / this article / this page / this doc | descriptive link; *this document* |
| for more information on | for more information about |
| etc. / and so on / and so forth | such as / including, then stop |
| e.g. / i.e. | for example / that is |
| and/or | rewrite the sentence |
| blacklist / whitelist / graylist | denylist / allowlist / provisional list, or rewrite the verb |
| master / slave (prose) | parent / replica (or the accurate pair); code tokens stay in `code` |
| hang / hung (system) | stop responding / isn't responding |
| hit (key or button) | press / click |
| hover | hold the pointer over / point to |
| hamburger / zippy / expando | the control's accessible name (**Menu**, expander arrow) |
| dummy variable | placeholder |
| utilize / leverage | use |
| commence | start / begin |
| consequently | so |
| a number of | some / many |
| as (meaning because) | because |
| once / since / while (if ambiguous) | after / because / although |
| may (possibility) | can / might |
| should | must / We recommend / can — pick one |
| could / would | can, or present tense |
| best / fastest / simplest / ensures / prevents | a verifiable fact |
| the API sees / tells / thinks | specifies / returns / detects |
| click on | click |
| check / uncheck / deselect (checkbox) | select / clear |
| create a new X | create an X |
| run the following command | say what the command does |
| cons | disadvantages |
| aka | also known as |
| America (the country) | the US / the United States |
| GCP / Cloud (the product) | Google Cloud |
| CLI (generic) | the named CLI (Google Cloud CLI, …) |
| drop-down (noun) | list / menu |
| dialog box / pop-up | dialog |
| filename / file name | filename |
| frontend / front-end | frontend |
| backend / back-end | backend |
| codebase / code base | codebase |
| lifecycle / life cycle | lifecycle |
| endpoint / end point | endpoint |
| healthcare / health care | healthcare |
| login (verb) | log in; sign in. Noun/adjective: as the product uses |
| tap (desktop) | click. Android / touch: tap |
| toggle (verb) | turn on / turn off / click the **Name** toggle |
| see (cross-ref) | keep *see* — it is the house verb for links |
