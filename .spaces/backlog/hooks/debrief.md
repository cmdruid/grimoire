# Backlog debrief routing

Edit each section to match this project. Debrief reads this file; the generic tracker API does not.

## tasks

File concrete, cold-actionable work that changes the project. Keep one outcome per item.

## issues

File what is wrong or risky, where it bites, and any evidence a future reader needs.

## feedback

File concrete friction or a useful observation from doing the work, including the affected skill or workflow.

## routines

File a deduplicated candidate only when it states all four: a recognizable trigger; the repeated
response or rediscovered decision; the cost, risk, or confusion worth reducing; and an observable
completion or verification boundary. Evidence names the strongest available basis. If recurrence is
inferred rather than observed, say why that expectation is grounded.
