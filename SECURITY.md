# Security policy

## Report a vulnerability

Do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Report them through GitHub private vulnerability reporting:

https://github.com/cmdruid/grimoire/security/advisories/new

If that form is unavailable, open a draft GitHub security advisory from the repository **Security**
tab.

In the report, include:

- The affected version, tag, or commit
- A description of the issue and why it is security-sensitive
- Steps to reproduce, or a proof of concept
- The potential impact
- Any suggested fix you already have

We will acknowledge the report, assess it, and follow up. If we confirm the issue, we will work on
a fix and coordinate disclosure with you when that helps.

## Supported versions

Security fixes target production snapshots on `main` and the latest production tag. Preview tags on
`dev` are not a supported security surface.
